# Workflow entry points

New theme: design → palette → scaffold → shell/apps/wallpapers as needed → test → demo → release → publish.
Existing bug: debug → the affected implementation skill → test.
Legacy theme: migrate → test → demo → release.
Small colour adjustment: palette → focused live test. Do not force every skill into every task.

All skills are portable and contain their own contract reference. Install the full set for the end-to-end workflow; individual skills may refer to the scaffold helper available in that skill.
