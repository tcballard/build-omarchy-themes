Build Omarchy Themes v0.2.1 ships the tooling to test the skills more carefully. The twelve theme skills are unchanged from v0.2.0.

Before comparing two versions of a skill, the annotation copy needs to hide which version ran. We found that line counts, file statistics and numbered grep output could give the answer away. This release closes those gaps while keeping fixture reads and helper-check output available to the annotators.

- **A repeatable evaluation pipeline.** Six pinned fixture cases, a headless Claude Code host, scratch preflight checks, annotation and adjudication tools, and reproducible analysis.
- **Better redaction.** Skill reads and metadata become one fixed placeholder. Safe helper commands keep their evidence, including commands wrapped with redirects, pipes or a change into the fixture directory.
- **Explicit run gates.** Missing host, annotator, mapping, audit or freeze evidence blocks execution. Interrupted and invalid sessions cannot quietly become a clean result.

The synthetic pipeline, R analysis, Rust helpers and release packaging are checked in CI. These are tests of the tooling, not measurements of model performance.

**The planned 144-session Claude evaluation remains NOT RUN.** Blinding remains partial, including the documented limitation around relative paths after an earlier directory change. No live Omarchy acceptance or improved model performance is claimed.
