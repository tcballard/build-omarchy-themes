# v0.3.0 — Make the theme work across the desktop

Building Familiar made the interaction between themes, personal settings and
applications harder to ignore. This candidate turns those lessons into reusable
guidance and checks across the twelve theme skills.

- **Keep personal settings personal.** Trace machine shell overrides separately
  from templates and theme sections, so a font or spacing preference survives switching.
- **Check the app as well as the palette.** Use a repeatable matrix for light/dark
  switches, still-open apps, selection, focus, disabled controls and scaling.
- **Make chosen requirements fail CI.** Opt into contrast thresholds, ignored-file
  failures and decoded-image checks. Existing advisory behaviour stays available.
- **Use the current shell contract.** Worked examples cover gradients, per-side
  borders and control states without hiding whole-section replacement costs.

These are authoring and project checks, not a sandbox, registry approval or an
accessibility certification. Video decoding, artwork rights and live desktop
acceptance remain separate. Familiar, Paint and Task Manager are suggested test
subjects when installed; compatibility with them has not been live-validated here.
The Claude evaluation remains NOT RUN. See evals/ACCEPTANCE.md for candidate evidence.

Publication and tagging follow review and CI for the exact candidate.
