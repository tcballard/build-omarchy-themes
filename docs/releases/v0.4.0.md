# v0.4.0 — Community lessons, lighter skills

Build Omarchy Themes v0.4.0 brings lessons from making and sharing my themes back into the twelve skills. There is less to read, clearer application defaults, and a simpler path from an idea to a theme on your own machine.

As themes such as Roadster have found an audience, people have spotted details I missed. Phil Sinatra’s [Roadster contribution](https://github.com/tcballard/omarchy-theme-roadster-8k/pull/7) caught blue folders and a navy Chromium scheme in a theme meant to feel near-black. That feedback now informs the default authoring workflow. Thanks, Phil.

- Choose application colours deliberately. New themes get explicit icon and Chromium settings, with portable syntax checks. Roadster’s choices are an example, not a palette imposed on every theme.
- Start where Omarchy starts. Read the installed theming guide and work with the dev channel’s Agents panel Theme button. A personal theme does not need an archive or registry submission before you can try it.
- Give the agent less to carry. The twelve skill instructions are about 28% shorter, with conditional detail kept in references and the same plain-file workflow across agent hosts.
- Check the current behaviour. Refreshed Quattro contracts cover theme staging, templates, shell colours and asynchronous application. Snapshot hashing now stays SHA-1 even when the caller inherits a SHA-256 Git repository.

The community feedback is improving how I build the next theme, as well as the ones already out there. Keep telling me where the desktop still looks wrong.

These are agent skills and authoring tools. Installing the bundle does not switch your desktop theme. Choose the archive for your host and verify it against `SHA256SUMS`.

Live end-to-end Omarchy installation and desktop acceptance remain outstanding. Phil reported live verification of Roadster’s two settings; that is separate from a fresh full installation. The planned Claude evaluation remains NOT RUN, and its documented working-directory provenance limitation remains open.
